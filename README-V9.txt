HN Admin Studio V9
==================
חבילה אחת לניהול האתר: גלריות וקטגוריות, עריכת מראה תמונות לא-הרסנית, פונטים וצבעים, Theme, SEO, Preview, פעילות אחרונה ותשתית עתידית לאזור לקוחות.

הערה חשובה: כלי התמונה שומרים הגדרות תצוגה (בהירות/קונטרסט/מסגרת וכו') ולא משנים את קובץ המקור. אחסון/עיבוד קבצים מתקדם ואנליטיקה בזמן אמת יתחברו בהמשך.
