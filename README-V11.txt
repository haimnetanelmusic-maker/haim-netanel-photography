HN Admin Studio V11
===================

שדרוגים עיקריים:
- Preview חי גדול ורחב יותר במסך עיצוב האתר.
- ספריית פונטים עבריים מורחבת ומחולקת לקטגוריות.
- תצוגה ויזואלית של “רגעים אמיתיים.” בכל פונט לפני בחירה.
- חיפוש פונטים ומועדפים מקומיים.
- פונטים נוספים בסגנון עגול, אלגנטי וכתב-יד.
- בחירה מהירה האם הפונט חל על שורת Hero לבנה/זהב, כותרות או טקסט רגיל.
- שמירה דרך Git Gateway ממשיכה לעבוד כמו ב-V10.

הערה: פונטים חיצוניים נטענים מ-Google Fonts. פונטים מסחריים אינם מצורפים ללא רישיון Web מתאים.
